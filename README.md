# Snake

## 遊戲說明

這是一款線上多人連線貪食蛇遊戲，使用 Java 開發，並通過 Socket 技術實現 Client-Server 架構。遊戲中，玩家控制貪食蛇，透過吃掉隨機生成的蘋果來增長蛇身並獲得分數，過程中需避開地圖邊界與其他玩家的蛇身。當玩家碰到地圖邊界或其他蛇時，遊戲結束。

## 作品特色

- Client端 提供單人遊戲與線上遊戲選項，線上遊戲無需手動輸入 IP 地址，會自動搜尋可用的 Server。
- Server端 顯示當前遊玩人數，並提供異常狀況下的手動關閉選項，避免 Client 異常時需要重啟遊戲，只需重新連線即可繼續遊玩。
- 在線上遊戲中，玩家與其他玩家的蛇有明顯區分，讓玩家能專注於自己控制的貪食蛇。
- 當線上遊戲結束時，會顯示玩家的分數以及當前其他在線玩家的分數，增添遊戲競爭性。
